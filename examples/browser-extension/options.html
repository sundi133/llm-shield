VotalAI Guardrails — Settings

Base URL of your Shield data plane (default: https://api.guardrails.votal.ai). The extension appends /guardrails/input.
Only needed if your endpoint sits behind a gateway that requires a bearer. Stored in local extension storage.
How long to wait for Shield before giving up. Default 45000 (45s) — a screen against the cloud data plane measures 14-20s, so a shorter deadline aborts ordinary requests. File screens add 2s per MB on top. Clamped to 1000-120000.
Applies to enforce mode. A timeout is not an approval: enforce that passes unscreened prompts when Shield is slow is not enforcement. Warn mode always fails open, because it never blocks anything.
